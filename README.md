# MedicalSystemPractice

Simple EMR practice app with a Node/Express backend and a React (Vite) client.

## Getting Started

Install dependencies:

```bash
npm install
cd client && npm install
```

Run the server:

```bash
npm start
```

Run the client:

```bash
cd client
npm run dev
```

## Notes

- Backend entry: `server.js`
- Frontend entry: `client/src/main.jsx`
